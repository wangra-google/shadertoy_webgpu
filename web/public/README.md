# Web Public Assets (`web/public`)

This directory contains static assets, pre-compiled WebAssembly (WASM) binaries, and their corresponding JavaScript glue code. These files are served directly to the client browser by the web server.

## Directory Purpose

The `web/public` directory hosts the compiled core engine and the client-side shader translation toolchain. Because browser environments cannot run C++ or perform complex shader translation (like SPIR-V to WGSL) natively, these tasks are offloaded to WebAssembly. The files in this directory are loaded by the frontend application at runtime to initialize the renderer and the shader compiler.

## File Overview

### [engine_wasm.js](file:///C:/src/shadertoy_webgpu/web/public/engine_wasm.js) & [engine_wasm.wasm](file:///C:/src/shadertoy_webgpu/web/public/engine_wasm.wasm)
The compiled WebAssembly binary and JavaScript glue code for the C++ rendering engine.
- **Source**: Compiled from the C++ codebase (specifically `src/core` and `src/platform/web`) using the Emscripten toolchain.
- **Function**:
  - `engine_wasm.wasm` contains the compiled C++ binary, including the WebGPU rendering loop, procedural geometry generation, and uniform buffers.
  - `engine_wasm.js` contains the Emscripten-generated JavaScript module wrapper (`createEngineModule`) that loads the WASM file, manages the WebAssembly heap, and exports the `EngineCore` class via Embind.

### [glslang.wasm](file:///C:/src/shadertoy_webgpu/web/public/glslang.wasm)
The WebAssembly binary for the Khronos `glslang` compiler.
- **Function**: Used by the frontend's compiler utility ([compiler.ts](file:///C:/src/shadertoy_webgpu/web/src/utils/compiler.ts)) to parse and compile GLSL shader source code into SPIR-V intermediate binary format (`Uint32Array`) directly in the browser.
- **Note**: Loaded dynamically at runtime by the `@webgpu/glslang` package wrapper.

### [twgsl.js](file:///C:/src/shadertoy_webgpu/web/public/twgsl.js) & [twgsl.wasm](file:///C:/src/shadertoy_webgpu/web/public/twgsl.wasm)
The JavaScript glue and WebAssembly binary for the `twgsl` translator.
- **Function**: Translates SPIR-V intermediate binaries (generated by `glslang`) into WebGPU-compliant WGSL shader strings.
- **Note**: Implements Google Tint's SPIR-V reader and WGSL writer compiled to WebAssembly. It is loaded via a `<script>` tag in the HTML wrapper and accessed via `window.twgsl`.

### [favicon.png](file:///C:/src/shadertoy_webgpu/web/public/favicon.png)
The icon file displayed in browser tabs and bookmark bars for the Shadertoy WebGPU Playground website.
